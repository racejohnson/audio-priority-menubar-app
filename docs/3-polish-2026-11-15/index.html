Hiding, in one paragraph

A hidden device leaves its list and is never picked automatically. It keeps its rank, so Show puts it back where it was. Hide the device in use and audio moves to the next one. The iPhone microphone starts hidden here so there is something to find.

Polished this round

Rows glide when the order changes. Switches are system blue, as in DayNight. The drop line takes the list's colour. Long device names truncate inside the sliders. Every control has a focus ring and works from the keyboard (Option-Up/Down re-ranks).

Selected state

Five ways to mark the device in use, from quietest to loudest, each in light and dark. Output is blue, input is violet. Round 2's badge is first; the rest add cues until the row can't be missed.

Drag handle

Six ways to offer the drag, built from system symbols and system habits. The middle row is shown as it looks under the pointer. Option-Up and Option-Down, and Move Up / Move Down in the row's menu, work with all of them.
